# HAI Seed website

Public product website at https://haiseed.ai/. GitHub Pages publishes the `main` branch from `/`; `www.haiseed.ai` redirects to the apex domain.

Routes: `/`, `/start-here/` (pricing and setup), `/aviation/` (reference deployment), `/start/` (contact). The Lithuanian commercial offer is in `downloads/`.

This site uses the approved HAI Seed logo masters and the self-hosted Hanken Grotesk font. The font licence is included in `assets/fonts/`.

Prepared from the public Garsink/muneron-site release `00a48af6cfa20fde608c8d6f3cf2b818dad2eacb`; product content and prices are unchanged. Contact remains `hello@muneron.com`. No analytics or form backend is added.
